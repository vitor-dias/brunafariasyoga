# Bruna Farias Yoga & Terapias

Site do estúdio de Hatha Yoga, meditação e Reiki da Bruna Farias, na Vila Galvão, em Guarulhos.

Site estático (HTML e CSS, sem build). O arquivo principal é `index.html` e as imagens ficam em `img/`.
Publicado pelo Netlify direto deste repositório: qualquer alteração na branch `main` vai para o ar automaticamente.
